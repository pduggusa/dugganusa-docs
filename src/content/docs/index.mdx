## What every integration has in common

- **One key.** The same `dugusa_` key works for the feed, the API, both MCP servers, the Edge Shield worker and the Checks Action.
- **Send it in a header.** `Authorization: Bearer <key>`. Keys in URLs end up in logs. See [Authentication](/authentication/).
- **Read-only.** Nothing you call changes anything on your side. You pull; you decide what to block.
- **You set the threshold.** Every indicator carries a confidence score from 0 to 95. Filter with `min_confidence`.
